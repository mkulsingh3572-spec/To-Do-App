# 📝 Mukul's To-Do App

A feature-rich To-Do App built with HTML, CSS & JavaScript featuring task priorities, due dates, progress tracking, filters, local storage, and responsive design.

## 🚀 Live Demo

👉 https://mkulsingh3572-spec.github.io/To-Do-App/

---

## ✨ Features

- ✅ Add Tasks
- ✏️ Edit Tasks
- 🗑️ Delete Tasks
- ✔️ Mark Tasks as Completed
- 🔍 Search Tasks
- 🔴🟡🟢 Priority Levels (High, Medium, Low)
- 📅 Due Dates
- 📊 Progress Tracking
- 📂 Filters (All, Active, Completed)
- 📈 Smart Task Sorting
- 💾 Local Storage
- 📱 Responsive Design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API
- Git & GitHub
